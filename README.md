# From Git to Gold — FreshCart Pipelines

Course assignment workspace for Git/CI, FreshCart ELT on Snowflake, Mage Iris ML, and RabbitMQ event streaming.

## Repository layout

```text
freshcart-pipelines/
├── README.md
├── requirements.txt
├── .gitignore
├── .github/workflows/ci.yml
├── elt/freshcart_elt.ipynb
├── iris_project_tutorial.ipynb
├── stream/dispatcher.py
├── stream/driver.py
├── tests/test_prepare_data.py
└── docs/assignment_reference.pdf
```

## Local setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
pytest -q
```

## Git workflow

```bash
git init
git add README.md requirements.txt .gitignore
git commit -m "chore: initialize pipeline repository"
git add tests .github
 git commit -m "test: add prepare_data CI gate"
git add stream
 git commit -m "feat: add RabbitMQ topic dispatcher and drivers"
```

Continue with separate commits for the ELT notebook, Mage blocks, SQL changes, and report. Do not make one final bulk commit; the assignment requires at least five meaningful commits.

## FreshCart ELT

Open `elt/freshcart_elt.ipynb` in Google Colab and run top-to-bottom. Configure Snowflake credentials using environment variables/secrets; do not commit `.env` or credentials. The notebook is based on the supplied classroom FreshCart notebook. Record actual outputs and screenshots for B1–B5.

## Mage Iris

Use the supplied `Maze_ML_PipeLine.ipynb` as the classroom build/run walkthrough. The actual Mage project folder is generated by running its cells. Copy the generated `iris_project/` folder into this repository before submission.

## RabbitMQ

Start RabbitMQ locally or use a hosted broker. Set `RABBITMQ_URL` outside Git. In separate terminals:

```bash
python stream/driver.py Ravi 'bangalore.koramangala.*'
python stream/driver.py Arjun 'bangalore.*.ride'
python stream/driver.py Control 'bangalore.#'
python stream/dispatcher.py
```

The dispatcher intentionally omits `zone` on every tenth message. Drivers NACK and discard those messages; valid messages are ACKed.
